# jQuery To-Do List Application

A simple To-Do List application developed using jQuery and HTML to manage daily tasks dynamically.

## Features

- Add new tasks
- Display tasks dynamically
- Mark tasks as completed
- Delete tasks
- Interactive user interface
- DOM manipulation using jQuery

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery

## Concepts Practiced

- jQuery selectors
- Event handling
- DOM manipulation
- Click events
- Dynamic HTML elements
- JavaScript functions
